CRISPy-web 3.0 Scoring System

1. Off-Target Effect Scoring (CRISPR/Cas9 Mode)

Off-target potential is evaluated according to the systematic scoring matrix 1. For each possible mismatch between the 13 bp non-seed region of the sgRNA and the genomic DNA, the algorithm assigns a context-dependent penalty score reflecting the nucleotide change and its position. Larger scores indicate a lesser impact on editing efficiency. When two or more off- target sites are detected, the algorithm incorporates a distance-based penalty (combine_eff) that adjusts the overall efficiency according to the distance between off-target loci, as shorter distances are more detrimental to editing fidelity.

2. sgRNA Intrinsic Efficiency Scoring

The intrinsic activity of each sgRNA is calculated by aggregating position-specific and dinucleotide features identified in several foundational studies 2-4. At each nucleotide position of the 20 bp sgRNA, empirically determined efficiency contributions are summed to produce a preliminary activity score.

3. Comprehensive Scoring

To obtain a final comprehensive score, the intrinsic efficiency score is adjusted by subtracting the cumulative off-target effect penalty. The result is normalized via a sigmoid transformation:
score = 1 / (1 + exp(–raw_score))
as proposed in the CHOPCHOP v3, ensuring all scores are mapped between 0 and 1 for intuitive interpretation.

4. CRISPRi Mode

For CRISPR interference, the scoring system uses a position-weighted matrix 2. Each of the 20 nucleotides in the sgRNA is assigned a positional activity value; these are summed, and the aggregate is normalized via the same sigmoid function as above to yield the final CRISPRi guide score.
